# The Aesthetic Way

Editorial, mobile-first website for The Aesthetic Way, built with Next.js and TypeScript.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Vercel

Import this repository into Vercel. It uses the standard Next.js build settings and requires no environment variables.

Treatment availability and prices are displayed from the public Aesthetic Way booking catalogue captured during the build. All booking calls-to-action continue to the live Faces Consent booking flow.
